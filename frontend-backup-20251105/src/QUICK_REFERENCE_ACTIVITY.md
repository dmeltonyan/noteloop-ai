# Recent Activity - Quick Reference

## 🎯 One-Sentence Summary
Click any day in Recent Activity to see detailed session breakdowns with performance metrics.

---

## ⚡ Quick Start

### 1. **Find It**
Dashboard → Scroll down → "Recent Activity" section

### 2. **Click It**
Click "Today", "Yesterday", or "2 days ago"

### 3. **View It**
See your study sessions with full details

### 4. **Close It**
Click the day header again to collapse

---

## 📊 What You'll See

### Per Session
| Metric | What It Shows |
|--------|---------------|
| **Topic** | What you studied |
| **Time** | When you studied (e.g., 9:30 AM) |
| **Duration** | How long (in minutes) |
| **Difficulty** | i (easy), i+1 (medium), i+2 (hard) |
| **Cards** | Number of flashcards completed |
| **Accuracy** | Percentage of correct answers |
| **Progress** | What you accomplished |

### Daily Summary
- Total cards completed
- Number of sessions
- Average accuracy
- Encouraging message

---

## 🎨 Color Guide

| Color | Meaning |
|-------|---------|
| 🟢 Green | i difficulty (foundational) |
| 🔵 Blue | i+1 difficulty (current level) |
| 🟣 Purple | i+2 difficulty (advanced) |
| 🟢 Emerald bar | 85%+ accuracy (excellent!) |
| 🔵 Blue bar | 70-84% accuracy (good) |

## 🔍 Understanding Metrics

### Cards Completed
Normal range: **5-20 per session**  
Higher = More ground covered

### Accuracy
- **90%+** → You're mastering this!
- **70-89%** → Good progress, keep going
- **Below 70%** → Review these concepts

### Difficulty Levels
- **i**: You've already learned this (review)
- **i+1**: Perfect challenge for learning
- **i+2**: Stretch goal (harder but achievable)

## ❓ FAQ

**Q: Why can't I see older days?**  
A: Currently shows last 3 days. More history coming soon!

**Q: Can I edit session data?**  
A: Sessions are auto-recorded. Manual editing coming in v3.0.

**Q: What if a day shows 0 minutes?**  
A: You didn't study that day. Start a session to log time!

**Q: Can I export this data?**  
A: Export feature planned for future release.
