# NoteLoop AI - Quick Feature Reference

## 🎯 What's New & How to Use

### **1. AI Chat Assistant** 💬
**Where**: Floating button (bottom-right corner)
**What it does**:
- Ask questions about your learning
- Get explanations of concepts
- Get study tips
- Chat history saved automatically

**Try it**:
- Click the floating chat button
- Ask: "Explain machine learning"
- Ask: "How can I improve my learning?"
- Click minimize to hide/show

---

### **2. Upload Library** 📚
**Where**: Click "Library" in navigation header
**What it does**:
- Shows all your uploaded files
- See when uploaded, file size, concepts created
- Quick access to study materials

**Try it**:
- Upload multiple files
- Visit `/library` or click "Library" button
- See all your uploads listed
- Click "Study This Material" to start learning

---

### **3. AI Enhanced Explanations** ✨
**Where**: Quiz explanation sidebar (after answering)
**What it does**:
- Get deeper AI-powered explanations
- Understand concepts better
- Additional context and examples

**Try it**:
1. Answer a quiz question
2. View the explanation
3. Click "Get AI Enhanced Explanation" button
4. Read the enhanced explanation

---

### **4. Learning Analytics** 📊
**Where**: `/progress` page or API endpoint
**What it does**:
- Tracks your performance
- Suggests focus areas
- Adapts difficulty automatically
- Learns your study patterns

**Try it**:
- Answer several questions
- Visit Progress page
- See insights and suggestions
